# ADR-026 — MIT License

**Status:** Accepted

## Decision

CyberCore Conductor is licensed under the MIT License.

The repository's root `LICENSE` file carries this copyright notice:

`Copyright (c) 2026 Cybercore Tech`

This decision establishes the software license. It does not, by itself,
establish a contribution agreement, contributor license agreement, or
policy for accepting external contributions.

## Rationale

The MIT License provides a short, permissive license suitable for broad
software use and redistribution while retaining the copyright and license
notice requirements.

## Consequences

- A root `LICENSE` file contains the complete MIT License text.
- Copyright notices use `Cybercore Tech` as the holder.
- Contribution acceptance and governance remain a separate open decision.
- Changes to the project's licensing model require an explicit decision.
